# 筋トレ習慣トラッカー

毎日の筋トレ項目をチェックして、達成率と連続記録を記録するiPhone向けのシンプルなWebアプリです。
サーバーやアカウントは不要で、記録はiPhoneのブラウザ内（localStorage）に保存されます。

## GitHub Pagesで公開する手順

1. このフォルダの中身（`index.html`, `manifest.json`, `icon-*.png`）をGitHubの新しいリポジトリにアップロードする
2. リポジトリの **Settings → Pages** を開く
3. 「Source」を `main`ブランチ・`/ (root)` に設定して保存する
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになる

## iPhoneのホーム画面に追加する

1. iPhoneのSafariで公開したURLを開く
2. 共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選ぶ
4. 専用アイコンでホーム画面に追加され、アプリのように全画面で開くようになる

## データの保存について

- チェックした記録は端末のブラウザ内（localStorage）に保存されます。他の端末やブラウザには自動では同期されません。
- Safariの「履歴とWebサイトデータを消去」を行うと記録が消えるため、**バックアップを保存**しておくことをおすすめします。
- アプリ内の「バックアップ」カードから、
  - **バックアップを保存**：現在の記録をJSONファイルとしてダウンロード
  - **ファイルから復元**：保存しておいたJSONファイルを選んで記録を復元
  ができます。機種変更や再インストールの前後にご利用ください。

## ファイル構成

- `index.html` — アプリ本体
- `manifest.json` — ホーム画面追加時のアプリ名・アイコン設定
- `icon-32.png` / `icon-180.png` / `icon-192.png` / `icon-512.png` — 各サイズのアイコン
